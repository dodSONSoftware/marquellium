# Test Plan

M0 (2026-10-29). Layers per PRD §10.1; commands and milestone gates per §11.

## Commands

| Command | What it runs |
|---|---|
| `pnpm test` | Vitest: `src/core` unit tests, fixture-validation tests, golden render tests (M2+), state-machine tests |
| `pnpm typecheck` | `tsc --noEmit` |
| `cargo test` (in `src-tauri/`) | Rust unit + integration tests (durability, registry, workspace, assets) |
| `pnpm build:web` | Typecheck + production bundle |
| CI (`.github/workflows/ci.yml`) | All of the above + `cargo clippy` + `pnpm audit` / `cargo audit` |

Test layers map to PRD §10.1:

| PRD layer | Where | Milestone |
|---|---|---|

| Performance | Benchmark scripts vs `fixtures/markdown/large-1mb.md` (NFR-001..003) | M3 gate, M5 report |

## Fixture inventory (created in M0, owned by the suite)

- `fixtures/markdown/*.md` — representative corpus: full GFM, CommonMark edges, Unicode, Mermaid+math, frontmatter, unsupported constructs, code-heavy, links/images. **Every file must parse** (fixture-validation test fails the suite if a fixture breaks the parser) and is the input for golden renders (M2) and M3V edit-preservation tests.
- `fixtures/markdown/roundtrip/*.md` — byte-exact open→save cases: `crlf.md`, `bom.md`, `no-trailing-newline.md`, `mixed-endings.md`, `trailing-spaces.md`, `cr-only.md`. Test: read bytes → write bytes → compare (Rust side, M1).
- `fixtures/markdown/edit-preserving/*.md` + `*.expected.md` — input/expected pairs proving localized edits leave everything else (endings, whitespace, BOM) untouched (M3V).
- `fixtures/hostile-input/*` — security corpus (see threat model T1/T2/T3/T7/T8).
- `fixtures/filesystem/workspace-a/` — a real workspace: nested docs, `assets/` with a real PNG, a symlink; regenerated by `fixtures/filesystem/generate.sh` (binary artifacts not committed as text).
- `fixtures/export/*.md` — AT-115 fidelity corpus (headings/links/images/tables/code/math/Mermaid) consumed by M5 export tests.

## Milestone gates (acceptance-criteria checks)

- **M0 (this milestone):** fixture-validation suite green (all corpus parses, roundtrip files byte-valid, hostile inventory complete); ADRs + threat model + release matrix committed; scaffold builds (`pnpm build:web`, `cargo check`).
- **M1:** durability suite green: byte-identical round-trip (all 6 roundtrip fixtures), conflict (external edit between read & save ⇒ no overwrite), crash snapshot (kill mid-write ⇒ original intact), symlink/traversal rejection, BOM/encoding refusal flow, registry concurrency (AT-104/117 contract level), dirty/close state machine unit tests (AT-105/106/107/108 logic). **No renderer features before this gate.**
- **M2:** golden renders green for the whole corpus; hostile-input render tests green (no scripts, no dangerous URLs, Mermaid fallback within budget); outline stability (duplicate/Unicode headings); offline no-network test (NFR-006 spot check).
- **M3:** typing-latency spot check (NFR-003 target, 1 MB fixture), mode-transition tests (byte-identical switch across all modes, AT-101/102/103), shared undo continuity.
- **M3V (mandatory):** §1A.5 tests 1–8 and AT-110/111/112 against `edit-preserving` corpus + full `fixtures/markdown` — byte-for-byte switch stability, smallest-safe-region edits, draft lifecycle, protected constructs. **Failure ⇒ stop, document alternatives, do not relax.**
- **M4:** malicious-input + full technical-document corpus green; export fixtures generated (AT-115).
- **M5:** NFR measurements recorded (NFR-001..003, 008), P0/P1 acceptance matrix signed off.

## Known-divergence policy (renderer vs GitHub)

The renderer will not match GitHub in all cases (PRD §6.3 Compatibility). Divergences discovered in golden tests are recorded in `docs/divergences.md` with a fixture reference; unrecorded divergences fail the suite.
