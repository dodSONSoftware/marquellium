# Marquellium — M3V acceptance

Date: November 2, 2026. Baseline: `dc23ba4` plus uncommitted package E and subsequent fixes. This record supersedes the unfinished evidence-index checklist in the package E report; historical observations there remain unchanged.

**Decision: PASS for the representative M3V gate on macOS arm64.** G1–G7 and all eight PRD scenarios have automated and native evidence below. Final native acceptance used the rebuilt opt-in `Marquellium.app`, including the AppKit termination guard and minimized-prompt restoration. Actual Dock → Quit was operated with the user-authorized AppleScript fallback; the Computer Use Dock timeout is not treated as product evidence. Both native focus flags were recorded as `Ok(false)` before the no-focused-window Quit cases.

**Default-mode decision:** retain Source as the normal default and keep the bounded Visual prototype opt-in (`VITE_M3V_VISUAL_PROTOTYPE=1`). M3V establishes source-preserving transaction and lifecycle viability; the full supported Visual surface remains M4 work. FR-042's intended Visual default remains an open M4 delivery requirement. This is an explicit sequencing decision, not a claim that the default requirement is delivered.

M4 may now begin under a separate implementation task. This pass is not a release-readiness, signing, export, or Windows/Linux parity claim.

## Final native acceptance — November 2, 2026

The final candidate was built after both fixes below. Tests used disposable files and isolated app data in `/private/tmp/marquellium-m3v-fixed`; the original fixture bytes were retained separately. Normal user files and recovery records were preserved. The earlier build and observations above remain historical evidence, not substitutes for this final run.

### Defects found and corrected

1. Ordinary **Dock → Quit** terminated the pinned Tao 0.37.2 application without entering Tauri's `ExitRequested` guard. Added a macOS AppKit `applicationShouldTerminate:` override on a no-ivar subclass of the existing application delegate. It vetoes synchronous native termination and invokes the existing asynchronous document coordinator. Every other delegate callback remains inherited. A focused Rust regression checks identical layout, inherited callback dispatch and the cancellation reply. See [ADR-008](adr/0008-inline-draft-and-close-state-machine.md).
2. With every window minimized, resolution could remain hidden. The coordinator now restores, shows and focuses the target only for draft/canonical prompts; internal preparation and discard messages do not raise windows. Errors propagate through existing pending-request cleanup.
