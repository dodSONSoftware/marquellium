## Delivered behavior

| Area | Implementation and verification |
| --- | --- |
| Supported Visual editing | Rendered headings, paragraphs/soft lines, nested ordered/unordered lists, task toggles, blockquotes, emphasis, strikethrough, link/reference text and plain/empty table cells use revision-bound localized transactions. Formatting applies to the selected source leaf/block; insertion/removal controls create explicit structural transactions. Inline code, destination/structural edits and protected syntax remain available through source drafts. Direct text retains its accepted-input-event history granularity; draft Apply and table helpers each commit one transaction. |
| Tables | Insert tables, select rows/columns, add/remove rows/columns, choose alignment, edit/clear/refill empty cells, retain escaped pipes, whitespace, code and emphasized neighbors. Malformed/ambiguous helpers fail without changing canonical text. Empty-cell inputs remain mounted and focused while becoming populated cells. |

Display-math drafts use the existing lease/history/recovery flow; invalid expressions retain the last valid preview and disable Apply. Mermaid keeps its strict resource/security policy and last-valid draft behavior. |
| Frontmatter and navigation | Raw YAML stays byte-preserved; compact metadata visibility is persisted. Outline and rendering use the same dialect parser, so frontmatter cannot create a false heading. Source positions survive math/escaped-HTML preview transforms. Split scroll sync maps actual raw source blocks through the CRLF adapter, with a re-entrancy guard and a user toggle. |
| Workspaces | Native picker grants one canonical root per window. Files/TOC switching preserves the tree, and collapsing/reopening the sidebar recovers that window's existing grant. Lazy directories list Markdown/plain-text files; hidden entries and symlinks are omitted. Comma-separated exclusions support `*`, `**` and `?`. Directory scans, visible results and matching work are bounded. Closing a window revokes its grant. Workspace search returns saved-file matching lines with bounded previews and opens results through the normal document route. It is literal/case-sensitive, respects exclusions, and reports truncation/skipped files. |
| Local links | Discover inline/reference links and images; check local files and Markdown heading anchors without following external URLs. Relative navigation/validation uses the containing document and its explicitly granted workspace, never process cwd. Missing targets, malformed encodings and scope/symlink escapes are observable errors. Current-document anchors use canonical unsaved text; other Markdown targets are checked on disk. |
| Clipboard images | Explicit Paste image and image clipboard-paste events import native RGBA as PNG into a user-named adjacent assets folder. New files use exclusive creation; existing files are never overwritten. Insertion uses a URI-encoded relative path, inline for text/table cells and after non-text constructs so math/fences survive. Failed/stale insertion retains the created asset and reports its location. Pending imports block lifecycle preparation, and active lifecycle requests block native asset side effects. |
| Commands and defaults | Commands… / Cmd/Ctrl+Shift+P filters available commands, supports arrow/Enter/Escape and restores focus. Native Undo/Redo routes to shared document history or the owning inline draft. Document tools exposes link checks, image paste, metadata visibility and the configurable opening mode. Find/Replace from Read or Visual safely resolves drafts, switches to Source and focuses the actual CodeMirror search field. Fresh default is Visual; explicit existing Source choices are retained. |

## Validation and limits

- **483 frontend tests across 34 files passed**, including the complete 30-file Markdown corpus and hostile fixtures.
- **99 Rust tests passed; one existing subprocess-fixture entry ignored.**
- TypeScript, Clippy with warnings denied, normal release app build, bundled worker execution and final diff whitespace checks passed.
- Final evidence is retained under `docs/validation/2026-11-02/m4-*`. Earlier M3V logs retain their own provenance/counts. The final native log is content-free lifecycle evidence; detailed UI actions above were directly observed and are not inferred from process exit alone.

Resource limits remain explicit: Visual mapping is bounded to 2 MiB / 200,000 nodes / depth 32 and 60 displayed blocks per page. Inline previews are bounded to 16 KiB / 256 lines; tables to 100 rows / 20 columns. Oversized/ambiguous constructs retain Source access. Mermaid supports flowchart, sequence and class diagrams under strict policy; document callbacks, HTML, configuration, styles and external resources remain disabled. Clipboard import accepts native RGBA up to 32 MiB and writes PNG. Workspace listing caps scans at 10,000 entries / 2,000 visible entries and bounds exclusion complexity. Workspace search checks at most 1,000 directories / depth 16 / 2,000 files / 16 MiB, skips files above 1 MiB or invalid UTF-8 with an explicit count, and returns at most 200 matching lines. It searches saved disk content, not unsaved buffers. Anchor-content checks are limited to local Markdown/plain-text targets up to 1 MiB. These are visible, fail-closed boundaries, not silent normalization or parity claims.
